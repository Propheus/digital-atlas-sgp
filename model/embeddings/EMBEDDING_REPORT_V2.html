Applications

How these embeddings power the Digital Atlas platform.

Gap Analyzer
Find underserved areas
Compare embedding-predicted place counts vs actual counts per category and tier. Subzones where the embedding suggests demand but supply is low = opportunity.
Input: subzone embedding → Model predicts expected cafe/restaurant/retail counts → Gap = expected - actual
Comp Set Generator
Find similar locations
Given any subzone or place, find the K most similar by cosine similarity in embedding space. Powers benchmarking and expansion planning.
"Find 5 subzones most similar to Orchard for a premium cafe rollout"
What-If Simulator
Simulate location changes
Modify a subzone's feature vector (add 5 premium cafes), re-encode through the model, see which subzone it becomes most similar to.
"After adding 3 restaurants, this HDB town centre's embedding moves toward Bugis — signals dining hub potential"
Archetype Clustering
Classify neighborhoods
The 8 discovered clusters serve as neighborhood archetypes. Any new development can be classified into an archetype to understand its character.
8 archetypes: Empty, Urban Core, Heartland, Affluent, Premium, Outlier, Industrial, Mega Hub
Data Explorer
Visualize urban structure
UMAP projection shows all 332 subzones in 2D, colored by archetype. Interactive exploration of Singapore's commercial DNA.

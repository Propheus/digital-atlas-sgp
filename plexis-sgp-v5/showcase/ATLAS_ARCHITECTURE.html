🚇 LTA DataMall feeds datamall2.mytransport.sg

Every mobility signal comes from these LTA DataMall datasets, snapped to hex:
  • Passenger Volume — O-D Bus Stops (242 MB) → od_throughput, in/out trips, net flow, self-containment
  • Passenger Volume — O-D Train Stations (37 MB) → rail commute flows
  • Passenger Volume — Bus Stops → time-of-day taps bus_taps_* (am · midday · pm · night · offpeak)
  • Passenger Volume — Train Stations → daily_train_taps, mrt taps by window
  • Bus static (GTFS) — stops · routes · trips · calendar → headways by window
  • Carpark Availability v2 → carpark_count_avail, carpark_lots_avail
  • Traffic Speed Bands v3 → speed_band_avg, jam_pct, dyn_avg_speed_kmh
  • MRT/LRT station exits + rail network (geojson) → access & reach

Why this shape. Everything below the agent layers is review-free and exam-gated — the representation encodes what a place is, never how popular it is. Agents never touch raw data; they call tools over the embeddings and packs, so every product inherits the same clean, validated substrate.

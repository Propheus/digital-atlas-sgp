What's in the box

Two files. Each row is one place or one neighbourhood turned into a short list of numbers, where distance = functional similarity. Same kind of thing sits close together — wherever it is on the island. That's the whole magic; everything below is built on it.

🏘️ HEX — the neighbourhood fingerprint

hex8_embedding_plexis_e1_256d.parquet · 1,191 × 256
  • Built from 801 city measurements — people, buildings, transit, places, business, rent, flows.
  • Distance answers "which neighbourhoods work the same?"
  • Join key: hex8_id.

📍 PLACE — the venue fingerprint

place_embedding_plexis_p1_64d.parquet · 190,591 × 64
  • Built from what a place is + its 400 m world + the kind of spot it sits in.
  • No ratings, no reviews — purely structural (audited).
  • Join key: id → links to the full places table for name/category/lat-lng.

Starter kit — the only three operations you need

Vectors are unit-length, so cosine similarity is just a dot product — one line finds the nearest neighbours of anything across the whole city. Golden rule: use the vectors RAW. Never re-standardise the columns — it destroys the validated geometry.

# pip install pandas numpy pyarrow
import pandas as pd, numpy as np

P = pd.read_parquet("place_embedding_plexis_p1_64d.parquet").set_index("id")
Z = P.to_numpy(np.float32)                  # 190,591 x 64, unit vectors

# 1) TWINS — "places like this one" (cosine = dot product)
def twins(place_id, k=12):
    sims = Z @ P.loc[place_id].to_numpy()    # one matmul, whole city
    top  = np.argsort(-sims)[1:k+1]
    return P.index[top], sims[top]

# 2) BRAND DNA — the centroid of a group is its "kind of place"
def dna(ids):
    v = P.loc[ids].mean(); return v / np.linalg.norm(v)

# 3) MISFIT — how far a place sits from its own street's crowd
#    group by hex8_id, compare each member to the group mean → low = odd one out

The hex file works exactly the same way — swap the parquet and the join key. Everything in the live apps (twins, galaxy, ghost maps) is built from these three moves.

The golden rules

  • Use the vectors RAW — never re-standardise the columns.
  • Similar ≠ nearby — if your result is just "things close together", you've found geography, not function.
  • Prove it — hide some data, predict it back. A demo that survives a hidden-answer test beats a pretty one that doesn't.
  • hex8 + places only — that's the whole toolbox. Constraints breed creativity.
